Which file for SketchUp?
  1. SketchUp on a computer: File › Import the 3D model (.dae). Paving, lawn and beds arrive as coloured surfaces; walls, planters and pergola as simple shapes.
  2. Free SketchUp in a browser: import the plan image. Click once to place it, then type the width printed on the image (for example 23.2m) so it's to scale, and model over it.
  3. The DXF is a 2D base plan for any CAD program (choose Meters when importing).
